# Pantine B. Hernando — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It has no dependencies or build step.

## Run locally

Double-click `index.html`, or open it in any modern browser.

## Customize

- Update the contact details and OJT summary in `index.html` whenever your CV changes.
- Update project and certification content as your work grows.
- Certificate PDFs are stored in the `certificates` folder and linked from the certification list.
- The profile photo is stored at `assets/pantine-hernando-profile.png`.
- Project screenshots for Conexia, REVORA, and LIFE are stored in the `assets` folder.
- Adjust the theme colors at the top of `style.css`.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, and select the branch containing these files with the folder set to `/ (root)`.
